# VISUALS — Lyrics Video & Cover Art Portfolio

Modern, high-converting landing page for music artists to order 3000x3000px single/album covers and animated lyrics videos.

## Features
- **Modern Dark Aesthetic**: Styled inspired by dark neon crimson aesthetic with subtle animations and glassmorphism.
- **Multilingual Support (i18n)**: Russian (RU), Romanian (RO), English (EN).
- **Auto Currency Detection**: Detects user currency (RUB, EUR, USD, MDL, RON) by timezone/locale, with manual switcher.
- **Two Conversion Funnels**:
  1. *Direct Contact ("Обсудить проект")*: Opens direct messaging channels (Telegram, Instagram, WhatsApp).
  2. *Self-Service Order Brief ("Оформить заказ")*: Complete brief form with auto-formatted Telegram message link and summary.
- **Zero Hosting Costs**: Deployed on GitHub Pages.
